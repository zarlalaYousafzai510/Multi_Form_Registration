# Multi-Step Registration Form

## About
A simple registration form built using HTML, CSS, and JavaScript. It collects user information in three steps.

## Features
- Personal information
- Contact information
- Account information
- Next and Previous navigation
- Form validation
- Password confirmation
- Progress bar
- Review and edit details
- Automatic draft saving using localStorage
- Registration success message

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Files
- `index.html` — Form structure
- `style.css` — Styling
- `script.js` — Form functionality
